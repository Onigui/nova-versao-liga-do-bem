## 🎯 Como Usar (SUPER SIMPLES)

### Opção 1: Build Manual (Recomendado)

1. **GitHub** → **Actions**
2. Clique em **🤖 Build Android APK (Capacitor)**
3. **Run workflow**
4. Escolha:
   - Build type: **release**
5. **Run workflow**
6. Aguarde **~5-10 minutos** ☕
7. **Download** dos Artifacts

**PRONTO! Sem token, sem conta, sem limites!** 🎉

### Opção 2: Build Automático (Push)

```bash
git add .

git push origin master
```

→ Build automático em 5-10 minutos!

## 🔍 Se Algo Der Errado

### Build Falhou?

1. **Veja os logs:**
   - Actions → [Workflow] → Logs

2. **Problemas comuns:**
   - Dependências: Corrigido automaticamente
   - Gradle: Configurado automaticamente
   - Permissões: Workflow já corrige

3. **Teste local (opcional):**
```bash
cd /workspace/mobile
npm install
npx cap sync
cd android && ./gradlew assembleRelease
```

### APK Não Instala?

1. **Habilitar "Fontes Desconhecidas"**
2. **Desinstalar** versão antiga
3. **Verificar** Android 5.0+ (API 21+)
